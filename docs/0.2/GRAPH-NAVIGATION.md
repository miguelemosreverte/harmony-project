# Let the infographic speak

The workflow scene explains what happened. Its bottom graph only shows the
available route and selected moment. This supersedes the labeled step-card layout.

- [ ] Replace workflow step cards with connected circles, a selected ring, and
  recognizable success/refusal endpoints. Preserve direct selection and history.
- [ ] Declare shared branch prefixes explicitly in presentation data. Draw their
  nodes once; never guess a branch from a label or code search.
- [ ] Keep step names available on hover, keyboard focus, and to screen readers.
  Input answers still need visible names; they are not playback positions.
- [ ] Put a short, observed-state badge beside the active actor. Keep names,
  application boundaries, quantities, and document labels in the scene.
- [ ] Remove the observation sentence bar, duplicated step count, and revision
  footer from featured workflows. Keep provenance in their evidence view.
- [ ] Verify stable geometry, meaningful state changes, every branch address,
  mobile touch targets, and desktop/mobile screenshots. Refresh the served book,
  commit and push the checked result.

A declined application and a refused attempt are separate facts. The new badges
must preserve that distinction. Inspecting live progress must never submit a
command or imply that an unavailable future action has completed.
