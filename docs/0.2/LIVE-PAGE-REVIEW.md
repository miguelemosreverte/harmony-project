# Live page review

These captures follow actual participant sessions on the disposable Canton network.
A screen has one purpose and at most two visible interactions.

## live-entry

Purpose: Enter with a private participant link.

Next: Paste the link and enter the workspace.

Visible interactions: participant-link / Enter workspace →.

![live-entry](../../design/0.2/quiet-review/live-entry.png)
